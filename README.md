# 🐙 Takopi AI — Python 기반 장기 기억형 AI 대화 시스템

- **GitHub**: https://github.com/RoiSoleilKR/Takopi_project

**Takopi**는 Python과 Ollama를 활용하여 로컬 LLM에 캐릭터 페르소나와 장기 기억 기능을 결합한 AI 대화 프로젝트입니다.

일반적인 AI 대화 시스템을 넘어, 사용자와의 대화 기록을 저장하고 장기적으로 기억할 가치가 있는 정보를 추출하여 지속적인 상호작용이 가능하도록 설계했습니다.

## ✨ 주요 기능

### 1. 대화 기록 저장 및 참조
- 사용자와 AI의 대화 내용을 `conversation.json`에 저장합니다.
- 각 메시지에 역할(role), 내용(content), 시간(timestamp)을 기록합니다.
- 전체 대화 기록을 보존하면서 최근 20개의 메시지를 LLM에 전달하여 응답 생성에 활용합니다.

### 2. 장기 기억 후보 생성
- LLM을 활용하여 사용자 입력에서 장기적으로 기억할 가치가 있는 정보를 추출합니다.
- 추출한 정보를 다음 유형으로 분류합니다.
  - `name`: 이름
  - `profile`: 기본 정보
  - `preference`: 취향 및 선호
  - `project`: 프로젝트 및 지속적인 활동
  - `goal`: 장기적인 목표
  - `other`: 기타 장기 기억
- 기억 후보를 JSON 형식으로 구조화하여 저장합니다.

### 3. 의미 기반 기억 중복 검사
- 새롭게 생성된 기억 후보를 기존 장기 기억 및 기억 후보와 비교합니다.
- LLM을 활용하여 단순한 문자열 비교가 아닌 의미적 중복 여부를 판단합니다.
- 중복된 정보가 불필요하게 저장되는 것을 방지합니다.
- 기존 기억과 충돌하는 정보는 새로운 후보로 분류하고 별도의 검토 대상으로 남깁니다.

### 4. 사용자 승인 기반 장기 기억 관리
- `memory_review.py`를 통해 생성된 기억 후보를 검토합니다.
- 사용자는 기억 후보를 승인하거나 보류할 수 있습니다.
- 불필요한 후보를 폐기하거나 내용을 수정한 뒤 승인할 수 있습니다.
- 승인된 정보는 적절한 유형에 따라 `memory.json`에 등록됩니다.
- 승인이 완료된 후보는 후보 목록에서 제거됩니다.

### 5. 장기 기억의 대화 활용
- `memory.json`에 저장된 정보를 읽어 LLM에 전달할 프롬프트 형태로 변환합니다.
- 변환된 정보를 LLM에 전달하여 이후 응답 생성에 활용합니다.
- 사용자에 관한 정보와 선호, 목표, 프로젝트 등을 지속적으로 참조할 수 있습니다.

### 6. 시간 인식 기능
- 대화 기록에 저장된 timestamp를 활용합니다.
- 가장 최근 AI 응답 이후 경과 시간을 계산합니다.
- 계산된 시간 정보를 LLM에 전달하여 시간의 흐름을 반영한 자연스러운 대화를 지원합니다.

```text
Takopi/

│   └── JSON 데이터 관리 및 장기 기억 처리

```

## ⚙️ 개발 환경 및 사용 기술

- **Programming Language:** Python
- **LLM Runtime:** Ollama
- **Language Model:** Gemma 4 E4B
- **Model Name:** `takopi2`
- **Data Storage:** JSON
- **Development Environment:** Visual Studio Code

## 🚀 설치 및 실행 방법

### 1. 사전 준비

- Python 설치
- Ollama 설치
- Ollama에서 사용할 모델 준비
```bash
ollama pull gemma4:e4b
ollama create takopi2 -f Modelfile
```

### 2. Python 패키지 설치

터미널에서 다음 명령어를 실행합니다.

```bash
pip install ollama
```

### 3. 모델 설정 확인

`main.py` 상단의 모델 이름이 실제 Ollama에 등록된 모델 이름과 일치하는지 확인합니다.

```python
MODEL = "takopi2"
```

Ollama가 실행 중인지 확인한 후 프로그램을 실행합니다.

### 4. 타코피 실행

```bash
python main.py
```

대화 종료 시 다음 명령어를 입력합니다.

```text
/bye
```

### 5. 기억 후보 검토

새로운 기억 후보가 생성되면 별도의 검토 프로그램을 실행합니다.

```bash
python memory_review.py
```

검토 메뉴에서 원하는 작업을 선택합니다.

- `1`: 기억 승인
- `2`: 기억 보류
- `3`: 폐기
- `4`: 수정 후 승인
- `5`: 검토 종료

승인된 기억은 `memory.json`에 저장되며, 이후 대화에서 활용됩니다.

## 💾 데이터 관리 구조

| 파일 | 역할 |
|---|---|
| `conversation.json` | 전체 대화 기록 저장 |
| `candidate_memory.json` | 장기 기억 후보 임시 저장 |
| `memory.json` | 승인된 장기 기억 저장 |

각 JSON 파일을 목적에 따라 분리하여 대화 기록, 기억 후보, 장기 기억을 독립적으로 관리하도록 설계했습니다.
